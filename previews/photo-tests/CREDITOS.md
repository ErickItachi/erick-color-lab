# Créditos das fotos

Kodak Lossless True Color Image Suite (Eastman Kodak), liberada pela Kodak para uso irrestrito. Imagens usadas: kodim04, kodim15, kodim18, kodim12, kodim13, kodim22.

O sinal de câmera (S-Log3, Apple Log, Canon Log 3, ACEScct) foi **simulado** a partir de cada foto (inversa exata do CINÉRA Neutral Rendering seguida da codificação do perfil). Não é footage gravada por essas câmeras.
